Titanic Survival Prediction

A machine learning project using the Titanic dataset to predict whether a passenger survived based on selected passenger characteristics.

Data Preprocessing

The original dataset contained 891 rows and 12 columns. PassengerId, Name, Ticket and Cabin were removed. Missing values were also removed, resulting in 712 rows and 8 columns.

Features Used

  • Sex
  • Age
  • SibSp
  • Parch
  • Fare
  • Embarked

Machine Learning Model

Logistic Regression was used to predict the Survived target variable.

Model Preparation

OneHotEncoder was used for categorical variables, while StandardScaler was used for Age and Fare. The dataset was split into training and testing data using a test size of 0.2.

Model Evaluation

A confusion matrix heatmap was used to evaluate the model's predictions.

What I Learned

This project helped me understand data preprocessing, feature selection, categorical encoding, feature scaling, logistic regression and model evaluation.
